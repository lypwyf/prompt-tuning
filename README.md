# Prompt 调优对比

一个用于对比「不同提示词写法对输出质量影响」的小工具。

**问题背景**：同样一个任务，写不同的 Prompt，大模型的输出质量和稳定性差别很大。这个脚本用同一个任务跑 3 种 Prompt 写法，把输出并排摆出来对比，直观看出哪些技巧真正有效。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API Key（复制 .env.example 为 .env，填入智谱 key）
#    ZHIPU_API_KEY=你的key

# 3. 运行对比
python prompt_eval.py
```

## 对比的三版 Prompt

| 版本 | 做法 | 输出表现 |
|------|------|----------|
| A 基础提问 | 直接问「请介绍栈」 | 冗长、结构松散、格式不可控 |
| B 加角色设定 | 「你是计算机专业课老师…」 | 语气像老师了，但结构仍不稳定 |
| C 角色+示例+格式 | 角色 + 给格式模板 + 示例 | 严格按模板输出，干净稳定 |

## 结论

「明确角色设定、提供示例、限定输出格式」三者中，**真正提升输出稳定性的是「给示例 + 限定格式」**——模型会严格照你给的模板回答。角色设定主要影响语气和视角。

> 小提示：多跑几次，A、B 两版的输出每次都会有波动，C 版最稳定，这正是关键差别。
